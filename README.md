# Research Sequence

The RJN Voynich Grammar project now consists of two linked structural studies.

## Paper 1 — Functional Process-Operator Grammar

**A Recursive Structural Decipherment of Voynichese as a Hierarchical Functional Process-Operator Grammar**  
*From Primitive Glyphs to Macro-Sequences, Regime Dispatch, and Diagrammatic Recipe Systems*

Paper 1 establishes the functional system of Voynichese.

Its principal result is that Voynich tokens are not best treated as ordinary lexical words, but as compressed operator chains participating in a recursive hierarchical process grammar.

Paper 1 therefore reconstructs the primary functional layer:

> **WHAT operation, state, transition, transformation, transfer, regulation, carrier, result, phase, or closure is represented.**

The Paper 1 manuscript is included directly in the root of this repository.

## Paper 2 — Instructional Component Grammar

Paper 2 extends the functional reconstruction through direct manuscript-level palaeographic analysis.

Its principal result is that the stable functional glyph system does not exhaust the information present in individual Voynich glyph occurrences.

A second information layer exists within the internal construction of the glyphs themselves.

This component system specifies:

> **HOW a particular occurrence of a functional operator is internally instructed and realized.**

The resulting architecture is therefore:

```text
FUNCTIONAL LAYER      = WHAT

COMPONENT LAYER       = HOW

DIAGRAMMATIC LAYER    = LARGER-SCALE ORGANIZATION

These systems are complementary but non-isomorphic.

The component grammar does not derive the EVA-level functional meaning of a glyph.

Instead:

The functional system identifies the stable class of operation.
The component system specifies the internal realization of that particular occurrence.

Core Claim

Voynichese is reconstructed as a recursive hierarchical technical process notation.

Its information architecture operates at several interacting levels:

COMPONENT CONSTRUCTION
        ↓
GLYPH OCCURRENCE

FUNCTIONAL GLYPH CLASS
        ↓
TOKEN / OPERATOR CHAIN
        ↓
MACRO-SEQUENCE
        ↓
DIAGRAMMATIC / PAGE ORGANIZATION

The functional and component layers should not be interpreted as a single derivational alphabet.

The manuscript instead appears to preserve two parallel dimensions of information:

stable functional identity
+
variable instructional realization

A complete interpretation therefore requires both.

Strong Manuscript-Level Demonstration

One of the clearest demonstrations of the dual information model is provided by the EVA glyph family:

{k, t, f, p}

At manuscript level, the four forms produce a factorial structural relation:

                         corner-C absent   corner-C present

1 horizontal LINK              k                  t

2 horizontal LINKs             f                  p

The same upper-left C-component distinguishes:

k ↔ t

and

f ↔ p

while horizontal LINK multiplicity distinguishes the two structural families:

k / t = one horizontal LINK

f / p = two horizontal LINKs

The same component distinction therefore operates across two different EVA-level functional contrasts.

It cannot itself encode the EVA identity of either resulting glyph.

This provides direct manuscript-internal evidence that:

FUNCTIONAL IDENTITY ≠ COMPONENT INSTRUCTION

and supports the distinction:

EVA-level functional class = WHAT

internal component construction = HOW
Functional Process-Operator Grammar

The functional system reconstructed in Paper 1 remains the operational backbone of the model.

Voynichese is not decoded word-by-word.

It is parsed sequence-by-sequence.

LINE     != primary syntactic unit

FOLIO    != primary syntactic unit

SEQUENCE = primary syntactic unit

Glyphs form tokens.

Tokens form operator chains.

Operator chains form recursive macro-sequences.

Macro-sequences interact with manuscript-specific diagrammatic regimes.

Formal Grammar Overview

A simplified representation of the functional grammar is:

SYSTEM = REGIME_DISPATCHER(MACRO_SEQUENCE+)

MACRO_SEQUENCE =
      P_START?
    + SETUP_BLOCK+
    + TRANSITION_BLOCK*
    + Q_CORE_BLOCK+
    + CLOSURE_BLOCK+

TOKEN =
      PREFIX*
    + CORE
    + SUFFIX*

Q_CORE_BLOCK =
      Q_BLOCK+

Q_BLOCK =
      q
    + OPERATION_CLUSTER
    + LOCAL_CLOSURE*

A typical macro-sequence therefore follows approximately:

P_START
   ↓
SETUP
   ↓
TRANSITION
   ↓
Q_CORE
   ↓
CLOSURE

The grammar is recursive.

Active process blocks may contain smaller process structures, embedded transformations, local closures, and nested subsequences.

The functional distinction remains:

ee and ii

The repeated forms provide one of the clearest bridges between the functional and component systems.

At component level:

ee = C + C

ii = I + I

At functional level:

e = processed / previously transformed state

i = phase / sequential unit

The repetition therefore preserves transparent internal structure without requiring the component construction to semantically derive the functional class.

Same WHAT — Different HOW

A central prediction of the model is:

SAME WHAT
→ multiple HOW realizations allowed

The clearest examples are provided by EVA d.

Corpus-level analysis independently establishes:

d = transformation

Manuscript inspection shows that different d occurrences may possess substantially different internal component constructions.

Therefore:

The component grammar does not explain why d means transformation.

It specifies:

how this particular d instructs its particular transformation.

Different WHAT — Similar HOW

The reverse relation is also expected:

DIFFERENT WHAT
→ closely related HOW realizations allowed

The k/t/f/p factorial structure is the strongest current example.

The same corner-C distinction is reused across two independent functional contrasts.

This directly excludes a simple one-to-one mapping between component identity and EVA-level functional meaning.

Non-Identity Constraint

The combined model predicts:

SAME WHAT
→ multiple HOW realizations allowed

DIFFERENT WHAT
→ very similar HOW realizations allowed

DIFFERENT WHAT
+ completely identical full HOW
→ investigate

Repeated completely identical full internal constructions across genuinely different functional classes would require one of three explanations:

an additional informational variable has not yet been identified;
the functional classification requires revision;
the dual-layer model is incomplete.

This provides a direct falsification criterion.

The claim is not that every large diagram is literally an expanded glyph.

The manuscript repeatedly uses related organizational and constructional principles at several scales.

The page, diagram, textual sequence, token, and glyph may therefore participate in a shared process architecture without being semantically identical.

Color

The Herbal H baseline was used for rule induction.

The whole corpus was subsequently used for error checking, regime comparison, structural transfer, and later validation.

The Herbal H frequency profile should not be assumed to apply identically to every manuscript regime.

Witness-Control Rule

A token may not be corrected freely or semantically.

If an H-token breaks an operative structural rule:

the token is checked against whole-corpus frequency;
alternative witnesses for the same manuscript position are examined;
replacement is permitted only when another witness supplies a defensible reading at the same line and position;
unresolved forms are retained as problem tokens;
unresolved anomalies may not be used arbitrarily to expand the grammar.

Therefore:

A transcription problem must not be mistaken for a grammar problem.

and:

A grammar problem must not be solved through arbitrary transcription correction.

Manuscript-First Control

Paper 2 adds an additional requirement.

Component-level claims cannot always be resolved from EVA transcription alone.

Where internal glyph construction is material to the analysis, the manuscript image takes precedence.

Therefore:

A terminal or anomalous EVA form should not be treated as a grammatical counterexample until its manuscript microstructure and token boundary have been visually resolved.

Competing witness readings are retained where relevant rather than silently discarded.

Independent Validation

The project is designed to permit adversarial and out-of-sample testing.

Independent researchers are encouraged to select manuscript material not previously analysed in the papers or repository.

The preferred test is:

the external researcher selects the material;
the questions are defined before analysis;
the published model is applied without changing its rules;
the predictions are recorded;
the manuscript and corpus are then used to evaluate the predictions;
successful and unsuccessful results are both retained.

The central replication question is:

Can another researcher reconstruct the same architecture from the manuscript under the published rules?

Two-Track Replication

Independent validation should distinguish two separate tasks.

Track A — Functional reconstruction

Test whether the stable functional system can be independently recovered through:

corpus distribution
token structure
sequence position
recurrence
transition behavior
closure behavior
regime transfer

This tests the:

WHAT

layer.

Track B — Component reconstruction

Independently inspect manuscript glyph occurrences and test whether recurring internal constructions can be recovered through:

C/I component structure
LINK topology
orientation
mirroring
position
boundary realization
scope
embedding
host relations

This tests the:

HOW

layer.

The two tracks should converge without requiring either layer to be semantically derived from the other.
