## Core Architecture

The current reconstruction identifies two distinct but mutually necessary
information systems in Voynichese:

**WHAT — Functional layer**

Stable glyph-level functional classes, captured operationally through EVA,
participate in a recursive hierarchical process-operator grammar.

**HOW — Instructional component layer**

Individual manuscript glyph occurrences contain an additional internal
constructional grammar based on recurring components, connection topology,
LINK architecture, position, orientation, scope, boundary realization,
embedding, and host relationships.

The two layers are complementary but non-isomorphic.

> **EVA identifies WHAT operation or state is represented.  
> Component construction specifies HOW that particular occurrence is
> internally instructed and realized.**

A third, larger-scale diagrammatic layer organizes processes across folios,
illustrations, radial structures, special pages, and other manuscript regimes.

## Central Result

Voynich tokens are not treated as ordinary lexical words.

They behave as compressed operator chains embedded in larger recursive
process sequences.

Paper 1 reconstructs the stable functional system.

Paper 2 demonstrates that this functional system does not exhaust the
information present in the manuscript glyphs. Stable functional identity can
be realized through systematically different internal constructions.

Therefore:

    FUNCTIONAL LAYER       = WHAT
    COMPONENT LAYER        = HOW
    DIAGRAMMATIC LAYER     = LARGER-SCALE ORGANIZATION

## Strong Manuscript-Level Test

One of the clearest component-level demonstrations is the structural relation
among EVA k, t, f, and p.

                         corner-C absent   corner-C present
    1 horizontal LINK           k                  t
    2 horizontal LINKs          f                  p

The same upper-left C-component distinguishes k from t and f from p,
while horizontal LINK multiplicity distinguishes the two structural families.

The same component distinction therefore operates across different
EVA-level functional contrasts and cannot itself encode either resulting
functional identity.

This provides direct manuscript-internal evidence that functional identity
and internal component instruction constitute distinct information layers.

## Reproducibility

The project is designed to permit independent testing rather than requiring
acceptance of an interpretation.

The repository contains:

- working Voynich corpus
- witness-control material
- parser and parsing documentation
- functional operator framework
- macro-sequence grammar
- component-level reconstruction
- manuscript-first retranscriptions
- quantitative tests
- key-folio demonstrations
- falsification and replication criteria

The working corpus derives from the EVA/Takahashi transcription tradition.
Authorship of the underlying raw Voynich transliteration is not claimed.

The original research contribution consists of the preprocessing and
witness-control procedures, functional reconstruction, structural grammar,
parser framework, component reconstruction, quantitative tests, and
interpretive model applied to that transcriptional basis.

## Transcription and Witness Control

A reproduction attempt should use the documented witness protocol.

The functional grammar was initially developed from a controlled Herbal H
baseline rather than an uncontrolled mixed transcription.

Core principles include:

- H as the primary working witness in the derivation baseline
- comparison with alternative witnesses when a form is anomalous
- no semantic correction of readings
- replacement only from the same manuscript position in another witness
- unresolved forms retained as problems rather than used to expand the grammar
- manuscript inspection taking precedence when component-level palaeography
  cannot be resolved from EVA alone

The Herbal H baseline is the derivation base for the earlier functional work;
it is not assumed to represent the frequency profile of every manuscript
regime.

## Independent Validation

The model makes falsifiable predictions.

It predicts that:

1. the same functional class may possess multiple internal instructional
   realizations;
2. different functional classes may possess closely related internal
   constructions;
3. recurring component contrasts should be reproducible across independent
   manuscript examples;
4. witness disagreements should concentrate disproportionately at graphical
   distinctions that EVA handles imperfectly;
5. genuinely different functional classes should not repeatedly show completely
   identical full component constructions unless an additional informational
   variable has been missed or the functional classification requires revision.

Independent researchers are explicitly invited to select previously
unanalysed manuscript material and test whether the published rules reproduce
the same architecture.
